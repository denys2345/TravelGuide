# Нотатки з роботи з асистентом

## Запити, які дали корисний результат

1. «У `portfolio-react/src/components/Card.jsx` додай окремий стан уподобань через `useState`; кнопка має збільшувати лише лічильник своєї картки».
2. «У `portfolio-react/src/App.jsx` додай фільтри “Усі / Веб / Дизайн”, перемикач теми й контрольоване поле імені з привітанням; перевір незалежність станів карток».
3. «У проєкті `server/` створи Express API: GET `/api/projects`, POST `/api/contact`, JSON та CORS; підключи React-картки до відповіді локального сервера».

## Перевірка згенерованої логіки

Лічильник розміщений усередині `Card`, тому кожен екземпляр має власний стан. `useState` повертає поточне значення та функцію оновлення; її виклик ініціює повторний рендер компонента. Хук викликається на верхньому рівні компонента, а не всередині циклу чи умови. Фільтрація створює новий масив елементів, для яких умова `filter()` істинна.

- [React: useState](https://react.dev/reference/react/useState)
- [MDN: Array.prototype.filter()](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/filter)

Перевірено збільшення вподобання лише першої картки, перемикання фільтрів і теми та зміну привітання під час введення. Розширення React Developer Tools у цьому середовищі не встановлювалося: наявний браузерний інструментарій не керує розширеннями. Тому стан перевірено через інтерфейс і автоматизовані дії у браузері, а не через панель розширення.

## Перевірка помилки

Під час короткого діагностичного тесту в обробник кліку було навмисно внесено посилання на неоголошену змінну `nextCount`. Клік спричинив помилку `ReferenceError: nextCount is not defined`, а лічильник залишився без змін. Причина — змінну не визначено в області видимості обробника; помилковий вираз замінено на `setCount(count + 1)`, після чого перевірку повторено.

## Висновки

- Формулювати точний файл, очікувану поведінку й обмеження.
- Переглядати кожну зміну й перевіряти її тестами, зокрема граничними сценаріями.
- Звіряти пояснення API з офіційною документацією, не покладатися лише на відповідь асистента.
- Асистент був доступний у середовищі редактора; окрема інсталяція чи авторизація для цієї вправи не виконувалася.
