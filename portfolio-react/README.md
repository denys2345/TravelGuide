# TravelGuide React

Мінісайт із добіркою туристичних напрямків, створений на React і Vite. Картки формуються з масиву проєктів і отримують заголовок, опис та зображення через props.

## Запуск

```sh
npm install
npm run dev
```

Для перевірки й production-збірки виконайте `npm run lint` та `npm run build`.

## Локальне API

У першому терміналі перейдіть до `../server` і виконайте `npm install`, потім `npm start`.
У другому терміналі з цієї папки виконайте `npm run dev`. React-клієнт отримує картки
та надсилає контактну форму до локального API на `http://localhost:3000`.
