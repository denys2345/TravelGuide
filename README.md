# TravelGuide

## Опис проекту

TravelGuide — це платформа для туризму та подорожей, яка допомагає користувачам планувати подорожі відповідно до їхніх особистих вподобань.

Користувач зможе обрати країну або напрямок подорожі, вказати свої інтереси та отримати рекомендації щодо місць, які варто відвідати. Платформа також дозволить знаходити місцевих провідників, які добре знають історію, культуру та особливості обраного місця.

## Основні можливості

- пошук туристичних місць;
- персоналізовані рекомендації;
- пошук місцевих провідників;
- інформація про історію та культуру місцевості;

Tailwind CSS спрощує швидке створення адаптивних компонентів завдяки готовим утилітарним класам. Звичайний CSS зручніший для складних взаємопов’язаних стилів і централізованого оформлення всієї сторінки. У цьому проєкті Tailwind застосовано до карток і кнопок, а базові стилі та теми залишено у звичайному CSS.

Демонстраційний список публікацій і форма використовують API JSONPlaceholder. Для повторної збірки стилів запустіть `npm run build`, а для автоматичної перебудови під час розробки — `npm run watch`.
