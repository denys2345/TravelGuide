# TravelGuide

## Опис проекту

TravelGuide — це платформа для туризму та подорожей, яка допомагає користувачам планувати подорожі відповідно до їхніх особистих вподобань.

**Живий сайт:** [https://denys2345.github.io/TravelGuide/](https://denys2345.github.io/TravelGuide/)

Користувач зможе обрати країну або напрямок подорожі, вказати свої інтереси та отримати рекомендації щодо місць, які варто відвідати. Платформа також дозволить знаходити місцевих провідників, які добре знають історію, культуру та особливості обраного місця.

## Основні можливості

- пошук туристичних місць;
- персоналізовані рекомендації;
- пошук місцевих провідників;
- інформація про історію та культуру місцевості;
- встановлення як PWA та доступ до основного вмісту офлайн після першого завантаження.

## Технології

Основна версія — семантичні HTML, CSS, Tailwind CSS та JavaScript без окремого JavaScript-бандлера. Збірка основного сайту не потрібна: GitHub Pages публікує файли з кореня репозиторію; `npm run build` компілює Tailwind CSS у `tailwind.css`. Окремий клієнт у `portfolio-react` використовує React і Vite; його команда `npm run build` створює файли в `portfolio-react/dist`.

Макет для реалізації наданий як локальний експорт `Main sections.png`. Посилання на вихідний Figma-файл у матеріалах проєкту відсутнє.

## PWA

Manifest, іконки та service worker розміщені в корені сайту. Service worker кешує основну сторінку, стилі, скрипт і зображення після першого успішного завантаження; зовнішній API працює лише за наявності мережі.

Після локальних змін запустіть `npm run build`, а потім відкрийте проєкт через локальний HTTP-сервер. Service worker доступний у захищеному контексті HTTPS або на `localhost`. Публікація відбувається через GitHub Pages після оновлення гілки `main`.

Tailwind CSS спрощує швидке створення адаптивних компонентів завдяки готовим утилітарним класам. Звичайний CSS зручніший для складних взаємопов’язаних стилів і централізованого оформлення всієї сторінки. У цьому проєкті Tailwind застосовано до карток і кнопок, а базові стилі та теми залишено у звичайному CSS.

Демонстраційний список публікацій і форма використовують API JSONPlaceholder. Для повторної збірки стилів запустіть `npm run build`, а для автоматичної перебудови під час розробки — `npm run watch`.

Окремий React-застосунок міститься у [portfolio-react](./portfolio-react). Для інтерактивних карток і локального API запустіть `server` командою `npm start`, а React-клієнт — командою `npm run dev` у `portfolio-react`.
